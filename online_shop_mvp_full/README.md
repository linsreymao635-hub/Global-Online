# My Online Shop - Complete Flutter MVP Starter

Features: Login/Logout, Sign Up, Home, Products, Search, Categories, Favorites, Cart + quantity, Checkout, Delivery Address, Order History, Profile, Settings, API, MVP, Repository, API Service, Models, Basic Tests.

## Run
flutter pub get
flutter run

## Test
flutter test

## API
DummyJSON: https://dummyjson.com
Products: https://dummyjson.com/products
Login: https://dummyjson.com/auth/login
Create user: https://dummyjson.com/users/add

## Architecture
View -> Presenter -> Repository -> API Service -> Backend/API -> Model -> View

This is a learning starter. DummyJSON is a demo API; signup is simulated and order history is kept in memory. A production app should use a real backend/database and persistent order storage.
